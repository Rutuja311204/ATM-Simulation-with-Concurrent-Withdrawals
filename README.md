# 🏦 VaultSync Banking Management System

## 📌 Project Overview

VaultSync is a Banking Management System developed using **Spring Boot, Java, MySQL, HTML, CSS, JavaScript and Bootstrap**. The project allows users to perform secure banking operations and demonstrates **Concurrent ATM Withdrawals using Java Multithreading and Synchronization**.

---

## ✨ Key Features

- 🔐 Secure Customer Login
- 👤 Customer Account Management
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔄 Fund Transfer
- 💳 Check Balance
- 📜 Transaction History
- ⚡ Concurrent ATM Simulation
- 🧵 Real-Time Thread Monitoring
- 🗄️ MySQL Database Integration
- 🌐 REST API using Spring Boot

## 🗄️ Database Configuration

1. Create a database named **vaultsync_db**.
2. Update the database username and password in `application.properties`.
3. Import the required SQL tables.

---

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Configure MySQL in `application.properties`.
4. Import the database.
5. Run the Spring Boot project.
6. Open your browser.
7. Visit:

**http://localhost:8081**
